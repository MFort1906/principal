Esta página simula um site QUALQUER da Tennant. O chatbot aparece no canto ↘

Como este chatbot foi embutido

Só foi preciso colar estas duas tags antes de </body>:

<script>
  window.TennixChatbotConfig = {
    endpoint: "https://SEU-APP.onrender.com/api/chatbot",
    token:    "SEU_TOKEN_PUBLICO"
  };
</script>
<script src="https://SEU-APP.onrender.com/chatbot-widget.js"></script>

Troque SEU-APP.onrender.com pelo domínio real do seu app no Render e SEU_TOKEN_PUBLICO pelo valor da variável WIDGET_PUBLIC_TOKEN.
